# Bot

Romanzo di emancipazione robotica, costruito come un progetto editoriale versionato.

La scrittura canonica vive in `chapters/`; il contesto, i personaggi, la cronologia e le regole di continuità nelle rispettive cartelle. Prima di contribuire, leggere `AGENTS.md`.

Ogni nuova versione in `VERSION` viene pubblicata, dopo i controlli, tramite GitHub Actions come EPUB, DOCX, PDF e Markdown.
